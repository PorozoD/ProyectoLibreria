# libreria

# Pre requisitos
-	Mariadb
-	Dotnet 10
-	VSCode
# Pasos para hacer correr el proyecto
1.	Clonar el Repositorio
```
git clone https://github.com/PorozoD/ProyectoLibreria.git
cd ProyectoLibreria
```
2.	Crear la base de datos y las tablas, corriendo el archivo script.sql en su SGBD
3.	Correr la aplicacion
```
dotnet run
```
